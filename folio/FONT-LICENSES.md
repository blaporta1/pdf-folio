# PDF Folio bundled font licenses

PDF Folio bundles these font families from the Google Fonts repository:

- Inter
- Noto Sans
- Source Serif 4
- Lora
- JetBrains Mono
- Caveat
- Open Sans
- Montserrat
- Poppins
- Nunito
- Raleway
- DM Sans
- Work Sans
- Fira Sans
- Oswald
- Merriweather
- Playfair Display
- Fira Code

Each family is licensed under the SIL Open Font License 1.1. The complete license text is distributed at `public/fonts/OFL-1.1.txt`. The files come from the upstream [Google Fonts repository](https://github.com/google/fonts). This is a curated library, not a claim to include every font or writing system. PDF Folio also accepts user-supplied TTF and OTF files for the current browser session.
